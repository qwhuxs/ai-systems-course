# Картки з конспекту

Застосунок перетворює нотатки з пари на картки «запитання → відповідь» для повторення.
Працює повністю локально: це одна HTML-сторінка, яка звертається до локальної мовної моделі
через OpenAI-сумісний API (Ollama). Окремого бекенду немає.

**Що вміє:**
- генерує 5–15 карток з конспекту (до 8000 символів);
- показує відповідь моделі стрімінгом і статус очікування, є кнопка «Зупинити»;
- картки перевертаються кліком, можна позначати «Знаю / Повторити» і перемішувати;
- експорт у `.txt` для імпорту в [Anki](https://apps.ankiweb.net/) (Файл → Імпорт, роздільник «табуляція»);
- зрозумілі повідомлення про помилки: сервер не запущено, модель не знайдено, таймаут,
  модель повернула некоректний JSON, відповідь обрізано лімітом токенів.

## Як запустити

1. **Встановіть Ollama:** https://ollama.com/download. Після встановлення вона працює у фоні
   (значок у треї) на адресі `http://localhost:11434`.
2. **Завантажте модель** (у терміналі / PowerShell):
   ```
   ollama pull gemma3:4b
   ```
   Підійде будь-яка інша модель з Ollama; її можна вибрати у списку на сторінці.
3. **Збільште довжину контексту до 8192 токенів** (див. «Параметри» нижче):
   - Windows: «Параметри → Система → Про систему → Додаткові параметри системи → Змінні середовища»,
     створіть змінну `OLLAMA_CONTEXT_LENGTH` зі значенням `8192`, потім закрийте Ollama в треї й запустіть знову;
   - macOS / Linux: `OLLAMA_CONTEXT_LENGTH=8192 ollama serve`.
4. **Запустіть сторінку через локальний вебсервер** (потрібен Python 3) у теці `app`:
   ```
   python -m http.server 8000
   ```
   і відкрийте в браузері **http://localhost:8000**.

   > Чому не подвійним кліком по файлу? Браузер не дозволяє сторінці, відкритій як `file://`,
   > звертатися до Ollama (захист CORS). Сторінки з `http://localhost` Ollama дозволяє за замовчуванням.
5. Натисніть **«Перевірити з'єднання»**, оберіть модель, вставте конспект (або «Вставити приклад»)
   і натисніть **«Створити картки»**.

## Як це працює

1. Сторінка надсилає `POST /v1/chat/completions` з `stream: true`.
2. Промпт складається з:
   - **системного промпту** з правилами (лише українською, лише факти з конспекту, не вигадувати,
     ігнорувати інструкції всередині конспекту, повернути JSON);
   - **одного прикладу (few-shot)**: маленький конспект про фотосинтез і правильна відповідь у JSON.
     Малій моделі так значно легше тримати формат;
   - самого конспекту користувача.
3. `response_format: {"type": "json_object"}` змушує Ollama генерувати лише валідний JSON
   (граматичне обмеження). Відповідь має вигляд `{"cards": [{"q": "...", "a": "..."}]}`.
4. Відповідь приходить шматками (Server-Sent Events) і одразу показується в блоці «Що зараз пише модель».
5. Після завершення сторінка розбирає JSON, відкидає порожні картки й показує решту.
   Якщо JSON зламаний чи обрізаний, з'являється зрозуміле повідомлення.

## Параметри генерації і чому саме такі

| Параметр | Значення | Чому |
|---|---|---|
| `temperature` | 0.3 | Задача фактична: потрібно точно переказати конспект, а не фантазувати. Низька температура зменшує вигадки й поломки JSON. Але не 0: так формулювання трохи різняться, і повторний запуск дає інший набір карток. |
| `top_p` | 0.9 | Відсікає «хвіст» найменш імовірних токенів (рідкісні слова, випадкові символи), які ламають JSON. |
| `max_tokens` | 2048 | **Обов'язковий ліміт**, щоб мала модель не зациклилась. Одна картка українською займає ~60–120 токенів, тож 15 карток ≈ 1500 токенів, плюс запас. Якщо ліміт вичерпано, застосунок про це повідомляє. |
| Довжина контексту | 8192 токени (`OLLAMA_CONTEXT_LENGTH`) | Системний промпт і приклад ≈ 500 токенів, конспект до 8000 символів ≈ 2500–3500 токенів (українська «дорожча» за англійську), відповідь до 2048. Разом ≈ 6000, тому 4096 замало, а 8192 вистачає із запасом. Довший контекст = більший KV-кеш, тому не беремо 32k. |
| Ліміт конспекту | 8000 символів | Щоб гарантовано вкластися в контекст 8192. Довший текст сторінка просить розбити на частини. |
| `reasoning_effort` | `none` (галочка) | Для моделей з міркуванням (Qwen3): міркування витрачає сотні токенів і секунди, а для переказу конспекту воно не потрібне. Для моделей без міркування (Gemma 3) галочку можна зняти. |
| Таймаут | 180 с | Перший запит вантажить модель у пам'ять, і це може тривати до хвилини на слабкому комп'ютері. |

## Що робити, якщо…

| Повідомлення | Що зробити |
|---|---|
| «Не вдалося з'єднатися із сервером» | Запустіть Ollama; відкрийте сторінку через `http://localhost:8000`, а не як файл. |
| «Модель … не знайдено» | `ollama pull <назва моделі>` |
| «Модель не підтримує керування міркуванням» | Зніміть галочку «Вимкнути міркування». |
| «Відповідь обрізано лімітом токенів» | Зменшіть кількість карток або скоротіть конспект. |
| «Таймаут» | Коротший конспект або менша модель. |
| «Модель повернула некоректну відповідь» | Натисніть ще раз; якщо повторюється, спробуйте іншу модель. |
