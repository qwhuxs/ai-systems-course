# Перевірка якості та тестові сценарії

## А. 10 промптів для перевірки якості моделі (розділи 1.4 і 1.5)

Кожен промпт вставте в чат рантайму (`web/chat.html`, `stream_demo.py` або чат Ollama)
**до оптимізації** і **після**, а відповіді збережіть. Ті самі тексти можна вставляти й у застосунок.

Що оцінювати у відповіді: (1) усе українською; (2) факти лише з конспекту, без вигадок;
(3) запитання різні, без повторів; (4) формат JSON не зламаний.

**1. Ентропія**
> Зроби 5 карток для повторення у форматі JSON {"cards":[{"q":"...","a":"..."}]} з конспекту: Ентропія джерела за Шенноном — це середня кількість інформації на один символ повідомлення. Обчислюється за формулою H = −Σ p(i)·log2 p(i), вимірюється в бітах. Ентропія максимальна, коли всі символи рівноймовірні: H max = log2 N. Надлишковість R = 1 − H / H max.

**2. Код Хеммінга**
> Зроби 5 карток для повторення у форматі JSON {"cards":[{"q":"...","a":"..."}]} з конспекту: Код Хеммінга (7,4) кодує 4 інформаційні біти сімома, додаючи 3 перевірні біти. Він виявляє і виправляє одну помилку в кодовому слові. Позиції перевірних бітів — степені двійки: 1, 2, 4. Синдром показує номер позиції з помилкою.

**3. Wi-Fi стандарти**
> Зроби 5 карток для повторення у форматі JSON {"cards":[{"q":"...","a":"..."}]} з конспекту: Стандарт IEEE 802.11n (Wi-Fi 4) працює в діапазонах 2,4 і 5 ГГц і вперше використав MIMO. 802.11ac (Wi-Fi 5) працює лише в 5 ГГц. 802.11ax (Wi-Fi 6) додав OFDMA, що підвищує ефективність у мережах з великою кількістю пристроїв.

**4. Laravel MVC**
> Зроби 5 карток для повторення у форматі JSON {"cards":[{"q":"...","a":"..."}]} з конспекту: Laravel — PHP-фреймворк, побудований за шаблоном MVC. Модель (Eloquent) відповідає за роботу з базою даних, представлення (Blade) — за HTML, контролер обробляє запит і з'єднує модель із представленням. Маршрути описують у файлі routes/web.php. Міграції дозволяють змінювати структуру БД кодом.

**5. UML**
> Зроби 5 карток для повторення у форматі JSON {"cards":[{"q":"...","a":"..."}]} з конспекту: Діаграма варіантів використання показує акторів і функції системи. Діаграма класів описує класи, їхні атрибути, методи та зв'язки: асоціацію, агрегацію, композицію, успадкування. Діаграма послідовності показує обмін повідомленнями між об'єктами в часі.

**6. SQL JOIN**
> Зроби 5 карток для повторення у форматі JSON {"cards":[{"q":"...","a":"..."}]} з конспекту: INNER JOIN повертає лише рядки, для яких є збіг в обох таблицях. LEFT JOIN повертає всі рядки лівої таблиці, а для відсутніх збігів — NULL. Первинний ключ однозначно ідентифікує рядок, зовнішній ключ посилається на первинний ключ іншої таблиці.

**7. Трансформери**
> Зроби 5 карток для повторення у форматі JSON {"cards":[{"q":"...","a":"..."}]} з конспекту: Трансформер — архітектура нейромережі, представлена у 2017 році. Ключовий механізм — self-attention, який дозволяє кожному токену враховувати інші токени послідовності. Decoder-only моделі (GPT) використовують причинну маску, щоб не бачити майбутніх токенів.

**8. Квантизація**
> Зроби 5 карток для повторення у форматі JSON {"cards":[{"q":"...","a":"..."}]} з конспекту: Квантизація зменшує кількість бітів на вагу моделі: з 16 (fp16) до 8, 4 або 2. Це зменшує пам'ять і пришвидшує генерацію на залізі, обмеженому пропускною здатністю пам'яті. Що менше бітів, то більше падає якість; int4 зазвичай — розумний компроміс, а int2 сильно псує модель.

**9. Історія (не технічна тема)**
> Зроби 5 карток для повторення у форматі JSON {"cards":[{"q":"...","a":"..."}]} з конспекту: Києво-Могилянська академія заснована в 1632 році Петром Могилою об'єднанням Київської братської та Лаврської шкіл. Це був перший вищий навчальний заклад на теренах України. Навчання велося латиною, викладали філософію, богослов'я, риторику.

**10. Конспект англійською (перевірка мови відповіді)**

UDP is connectionless and faster, but does not guarantee delivery. TCP uses a three-way handshake: SYN, SYN-ACK, ACK.
